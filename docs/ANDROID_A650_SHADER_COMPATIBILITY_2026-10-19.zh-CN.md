# Adreno 650 片元 subgroup 兼容路径

骁龙 870／6GB 平板的系统 Vulkan 驱动只公布 Compute 阶段的 subgroup 支持。
原缓存中 182 个片元模块含有 `OpGroupNonUniformShuffle`；离线通过
`spirv-val` 不代表这些模块能够在该设备的 Fragment 阶段合法执行。
这与主城黑块、异常几何的关联仍须真机对照，不能把兼容修复当成已验证的性能收益。

新增显式离线选项 `quad_transfer_v1` 和 `quad_transfer_readonly_v2`。
默认仍为 `native`，Mali／新高通不自动切换。变更仅在原着色器翻译工具链与
Vulkan 后端，不引入 CPU 模拟或游戏地址补丁。

转换仅处理能够证明是片元四像素组内、固定 XOR 1／2 的交换。
入口处以细粒度导数重建相邻值，32 位值拆成两个精确可表示的 16 位整数，
避免直接对浮点 NaN／Inf 做差导致位模式丢失。无法证明的来源、交换形态或
控制流拒绝编译，不退回设备不支持的片元 subgroup。

第二种配置允许有界的只读来源：静态索引常量、启用 robustBufferAccess 的
只读 SSBO，以及受限的显式 LOD 0 二维读取。新增的前移读取使用实际图像尺寸
检查并钳制访问坐标，越界逻辑结果为零；未知函数、原子／屏障及资源写入拒绝。
它会增加部分入口读取和整数运算，是兼容代价，不声称比原生 subgroup 更快。

元数据只对实际转换的模块标记新属性。运行时要求单采样、填充三角形与满足
坐标精度的设备上限；只读扩展还要求所有实际图形阶段不写资源，并逐 draw 核对
实际 VkImage 的附件写入冲突。二维采样视图允许单独 COLOR 或 DEPTH aspect，
STENCIL／混合 aspect 拒绝。准备好的 PSO、启动预热和模块替换均保留对应约束；
不将该只读证明用于 Pixel Local 输入附件替换。

交付验证器核对配置、反射与元数据属性一致，并检查该配置的片元 SPIR-V
不再包含 subgroup 指令。原几何证明、栅格事实提取、产物哈希及 sidecar
再生成检查保持原规则。

验证边界：实际翻译 Pass／SPIR-V emitter 的独立 GPU oracle，以及运行时
COLOR／DEPTH、别名写入拒绝、串行／异步路径已完成宿主软件 Vulkan 验证。
这些测试不代替原游戏在 Adreno 650 上的画面、内存和持续游玩验证。
真机验收应使用完整重建的着色器链与对应宿主，进入原游戏后先采集官方
`dumpsys meminfo`，再执行操作、截图及原生命周期存档。
