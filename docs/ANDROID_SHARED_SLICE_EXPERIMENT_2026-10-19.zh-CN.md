# 共享切片地址布局实验（未接入游戏）

本分支基于共享 VkMemory／borrowed Buffer API，增加围绕已存在映射预留客体地址空间的事务化辅助函数。
它不拦截 malloc，不接管 SetHeapSize／NVN Pool，不更改主线游戏内存分配。

OS 匿名区域事务、权限及回滚测试通过；真实 Vulkan 映射周围的地址预留在宿主与高通测试均遇到 EEXIST。
因此不能把 OS 正例或 GPU 字节测试算作真实游戏地址布局成功。

新增 GPU-first-write 测试还发现：高通上对驱动映射做原脏页保护时，未预先访问的其它映射页可能读到错误数据。
取消这条保护的最小控制通过；现有生产 VMA staging 的纯 GPU 写入／原完成回填对照通过。
目前只证明测试路径差异，未查明驱动内部原因，不能归因为通用 Vulkan 回读错误，也不以预触页掩盖该问题。

此候选仍不能默认接入游戏。需要先关闭地址布局、初值与保护、共享缓存维护及异步完成写入的语义缺口。
本分支是保存中的实验，不是内存或帧率收益交付。
